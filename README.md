# 甘肃新煜科技工作台 · 运行与部署手册

> 版本：v6.6（黑橙科技主题 · 账号密码登录 · 管理员权限 · 跨平台独立运行 · 原生桌面 APP 打包 · 公有云一键部署 + 云端实时同步）
> 形态：**纯前端 PWA**（浏览器直接打开 + 可一键安装为独立 APP + 离线可用），配套零依赖 Node 协同后端实现多设备实时同步；另附 **Electron 外壳**可打包为 Mac `.app` / Windows `.exe` / Linux `AppImage` 真·原生桌面软件。

---

## 一、它能在哪里运行？

| 场景 | 怎么用 | 说明 |
|------|--------|------|
| 浏览器（本地/外部网络） | 用 Chrome / Edge / Safari 打开地址 | 无需安装，即开即用 |
| 手机/电脑「独立 APP」 | 浏览器「添加到主屏幕 / 安装应用」 | 全屏独立运行，图标在桌面，体验等同原生 APP |
| 离线 | 断网后照常使用 | Service Worker 缓存了全部代码与数据壳 |
| 多设备协同 | 启动后端，多设备开同一地址 | 实时同步、在线状态、广播更新 |
| 外部网络 / 公网 | 部署到服务器或内网穿透 | 团队成员异地访问同一工作台 |

## 二、本地快速开始（含多设备协同）

```bash
# 进入项目目录
cd workbench-app

# 启动零依赖协同后端（默认端口 8090，可用 PORT 环境变量覆盖）
node ../server/server.js
# 或： PORT=9000 node ../server/server.js
```

启动后访问：
- 本机：http://localhost:8090
- 同局域网其他设备：http://<本机IP>:8090（手机/其他电脑用同一地址即可协同）
- 后端已绑定 `0.0.0.0`，直接对外网/局域网开放。

> 不启动后端也能用：直接双击 `workbench-app/index.html` 以 `file://` 打开即可本地单机使用（登录、权限、数据均存于本机浏览器）。

## 三、安装为「独立 APP」（推荐给经常使用的同事）

### iPhone / iPad（Safari）
1. 用 Safari 打开工作台地址 → 点底部「分享」按钮
2. 选择「添加到主屏幕」→ 命名「新煜工作台」→ 添加
3. 桌面出现图标，点击即全屏独立运行（支持面容/两步返回）

### Android（Chrome / Edge）
1. 打开地址 → 地址栏右侧出现「安装」图标（或菜单「安装应用」）
2. 确认安装 → 桌面生成独立 APP 图标

### Windows / macOS（Chrome / Edge）
1. 打开地址 → 地址栏右侧「安装」图标（或菜单「应用 › 安装此站点为应用」）
2. 生成独立窗口应用，可固定到任务栏/ dock

> 安装后即为独立软件形态，不受浏览器标签干扰；离线、推送、全屏体验与原生 APP 一致。

## 四、放到外部网络 / 公网（团队异地协同 · 云端实时同步）

> 完整图文步骤见 **[DEPLOY.md](./DEPLOY.md)**（含 GitHub 推送、Railway / Render / Fly.io 一键部署、VPS/HTTPS 备选、故障排查）。

两种形态：

- **A. 全栈同域部署（推荐）**：把整个仓库（前端 ＋ `server/server.js`）部署到云平台，平台同时托管 PWA 与 `/api`。**打开平台域名 → 登录 → 自动连同源后端，多设备实时同步，零额外配置。** 仓库已内置 `server/deploy/` 下的 Dockerfile 与 Railway / Render / Fly.io 配置，一键即可。
- **B. 静态前端 ＋ 独立后端（混合）**：前端丢到 CloudStudio / Vercel / GitHub Pages，后端自托管在一台常驻服务器；前端「管理员 → 平台管理后台 → 系统设置 → 协同服务地址」填后端域名即开启同步。

> 生产环境建议：用 HTTPS 域名 + 反向代理；后端目前为演示级（账号哈希存于客户端，后端走 token 注册模式），正式上线请接入企业微信/钉钉/OAuth 并在服务端加盐存储密码。

## 五、账号、角色与权限

首次打开会进入**账号登录网关**。默认内置三个演示账号：

| 账号 | 密码 | 角色 | 能力 |
|------|------|------|------|
| `admin` | `admin888` | 管理员 | 全部功能 + 用户管理 + 系统设置 + 年度目标 + 数据备份/恢复 + 登录审计 |
| `manager` | `manager888` | 管理者 | 经营数据增删改查（项目/合同/人员/跑动/费用），不能管账号与系统 |
| `member` | `member888` | 成员 | 查看为主 + 填报跑动/业务费用，不能删除或结构性修改 |

**权限矩阵（参考主流平台管理员权限设计）**

| 权限项 | 成员 | 管理者 | 管理员 |
|--------|------|--------|--------|
| 经营数据查看 | ✓ | ✓ | ✓ |
| 项目 / 合同 增改 | ✕ | ✓ | ✓ |
| 项目 / 合同 删除 | ✕ | ✓ | ✓ |
| 跑动 / 费用 填报 | ✓ | ✓ | ✓ |
| 用户与账号管理 | ✕ | ✕ | ✓ |
| 系统设置 / 目标 | ✕ | ✕ | ✓ |
| 数据导出导入 / 清库 | ✕ | ✕ | ✓ |

管理员入口：左侧「系统 › 平台管理后台」（仅管理员可见）。可新增/禁用/删除账号、重置密码、查看登录审计、修改年度目标、导出/导入全量数据。

> 安全提示：密码在前端做哈希后存储于本机 / 同步库，**非高安全强度**。对外发布前请改为服务端校验并加盐。

## 六、数据安全与备份

- 数据默认存于浏览器 `localStorage`（键 `xy_workbench_v4`），单机离线可用。
- 管理员后台「导出全部数据」可下载 JSON 备份；「导入数据」可恢复并同步到其他设备。
- 启用协同后端后，所有设备的改动经 SSE 实时广播、落盘 `server/db.json`，刷新不丢失。

```

  js/overview.js      # 全域态势驾驶舱
  js/app.js           # 核心逻辑 + 登录/权限/管理后台 + 协同同步
```

## 八、打包为原生桌面 APP（Electron，可选）

除浏览器 PWA 安装外，`workbench-app/desktop/` 提供了 Electron 外壳，可打包成真正的原生桌面软件（Mac `.app` / Windows `.exe` / Linux `AppImage`），满足"独立 APP 软件"诉求。

```bash
cd workbench-app/desktop

# 安装依赖（首次）
npm install

# 开发预览：自动拉起协同后端并打开桌面窗口
npm start

# 打包发行版（输出到 dist/，跨平台需在各平台分别打包或用 CI）
npm run dist
```

要点：
- `main.js` 启动时会自动拉起 `server/server.js`（协同后端 8090），打开独立窗口加载工作台；关闭窗口即退出。
- `package.json` 已配 `appId=com.xinyu.workbench`、产品名「新煜工作台」、图标指向 `../icons/icon-512.png`。
- 打包后的 `.app/.exe/AppImage` 为离线可分发软件，双击即用，无需用户会装浏览器插件。

> 注意：Electron 打包需在各目标平台分别执行 `npm run dist`（Mac 打 `.app`、Windows 打 `.exe`、Linux 打 `AppImage`）；当前 `package.json` 锁定 `electron@^30` / `electron-builder@^24`。

## 九、日常维护

- **恢复示例数据**：左侧底部「恢复示例数据」（需管理员）。
- **升级**：替换 `workbench-app/` 文件即可；旧数据经结构补丁自动兼容，不丢数据。
- **清库重来**：浏览器清除站点数据，或管理后台「恢复示例数据」。
