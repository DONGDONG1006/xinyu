# 甘肃新煜科技工作台 · 协同后端

零依赖 Node 服务，提供 **登录鉴权 + 共享数据 + SSE 实时广播**，让 MacBook / Windows / iPhone / 华为 多设备
打开同一地址即可**协同编辑与联动**（任意一端保存，其他端实时刷新）。

## 运行

```bash
cd 项目根目录
node server/server.js
# 或自定义端口
PORT=8090 node server/server.js
```

启动后访问 `http://localhost:8090`（同一局域网内的手机用电脑 IP 访问，如 `http://192.168.x.x:8090`）。

## 协同机制

- 首次登录：服务端若尚无共享数据，则把本机 `localStorage` 中的数据作为权威副本上传。
- 任意一端保存（新增/编辑项目、合同、人员、费用、派单等）：前端 `fetch('/api/db')` 推送到服务端，
  服务端持久化到 `server/db.json` 并向其他在线设备广播。
- 其他在线设备通过 `EventSource('/api/stream')` 收到更新，自动合并并刷新界面，顶部显示"已协同"与在线成员。
- 离线（未登录 / 单独打开 PWA）：完全使用本机 `localStorage`，数据不跨设备；联网登录后自动并入共享副本。

## 文件

- `server/server.js` — 服务主程序（http + SSE + 静态托管，无第三方依赖）
- `server/db.json` — 运行时自动生成的共享数据（首次协同后产生，可删除重置）

## 说明

- 前端为纯静态 PWA（`workbench-app/`），服务端只负责"托管 + 协同"，不改造任何前端逻辑。
- Service Worker 已对 `/api/*` 请求放行（不缓存），保证登录与实时广播不被离线缓存干扰。
